Les bases du HTML

La structure minimale d'une page web.

Structure minimale


                        <!DOCTYPE html>
                        <html lang="fr">
                        <head>
                            <meta charset="UTF-8">
                            <title>Ma première page</title>
                        </head>
                        <body>
                            <h1>Bonjour</h1>
                        </body>
                        </html>

Le contenu visible de la page va dans <body>; les métadonnées vont dans <head>.
